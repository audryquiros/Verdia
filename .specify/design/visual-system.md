# Design — Sistema visual

## Identidad
- Forest Green `#285E45`
- Soft Green `#A9D29A`
- Cream `#F3F6EF`
- Graphite `#26342B`
- Sage `#E4EDE1`
- White `#FFFFFF`

## Tipografía
- Outfit ExtraBold: logo/wordmark.
- Manrope: títulos y cifras.
- DM Sans: interfaz y contenido.

## Principios
- natural;
- clara;
- tranquila;
- moderna;
- humana;
- no bancaria/fría.

La decoración orgánica nunca debe competir con cifras, balances o acciones.

## Responsive
Desktop:
- sidebar fija;
- dashboard modular;
- comparaciones amplias.

Mobile:
- navegación inferior;
- tarjetas apiladas;
- acciones táctiles.

Mobile no es desktop comprimido.
