## Datos
Administración debe priorizar:
A. datos operativos;
B. datos analíticos agregados;
C. datos financieros privados solo bajo acceso excepcional, justificado, limitado, temporal y auditado.

## Eventos
`eventos` registra actividad del sistema/producto con metadata mínima.

## Auditoría
`auditoria` registra acciones sensibles/admin:
actor, acción, entidad, resultado, metadata mínima y timestamp.

## Soporte
El acceso privado excepcional debe seguir:
solicitud → razón → alcance → aprobación → acceso limitado → expiración → auditoría.
