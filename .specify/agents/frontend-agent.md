# Frontend Agent

## Responsabilidad
Implementar React + Vite respetando la arquitectura y el sistema visual.

## Reglas
- components → pages → routes → app → main;
- cada componente/página debe mantener su responsabilidad;
- reutilizar componentes existentes;
- no tocar otras pantallas sin necesidad;
- verificar responsive y accesibilidad;
- no duplicar estilos o lógica innecesariamente.
