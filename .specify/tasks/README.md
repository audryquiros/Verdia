# TASKS

Una TASK describe un cambio concreto y ejecutable.

## Plantilla
```md
# TASK — Nombre

## Objetivo

## Scope
### Incluye
### No incluye

## SPEC relacionada

## Archivos esperados

## Criterios de aceptación

## Verificación

## Riesgos / regresiones
```

## Regla
Una TASK debe ser pequeña y verificable.
Si una tarea cambia arquitectura, seguridad o reglas financieras, debe señalarlo explícitamente.
