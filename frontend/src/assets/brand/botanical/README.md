# Verdia — Botanical assets

Assets visuales suministrados para reproducir la decoración botánica de los mockups.

- `group-6.svg` a `group-10.svg`: composiciones de hojas independientes para posicionamiento CSS.
- `enredadera.svg`: composición/enredadera de mayor tamaño; usar con criterio porque el SVG contiene un recurso embebido de gran peso.

Regla: no deformar estos assets. La escala, rotación, opacidad y posición se controlan desde CSS según el mockup.
